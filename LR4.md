# ЛР4: состояние и списки в «Попути»

Ветка `lr4` продолжает приложение варианта 24 из ЛР3. Новая логика сосредоточена на экране выбора мест: список переведён на `FlatList`, появились избранные места и фильтр, число пассажиров и расчёт стоимости. Общая структура исходного проекта описана в [PROJECT.md](PROJECT.md).

## Какие файлы изменены

| Файл | Что добавлено и для чего |
| --- | --- |
| `screens/SeatsScreen.tsx` | Основная часть ЛР4. `FlatList` показывает 16 мест через `data`, `renderItem` и `keyExtractor`. Здесь находятся состояния избранного, вкладки, числа пассажиров и выбранных мест, обработчики нажатий и расчёт суммы. |
| `data/trips.ts` | Поле `priceValue` хранит числовую цену билета рядом с текстовой `price`. Число нужно для умножения на количество пассажиров без разбора отформатированной строки. |
| `navigation.ts` | Параметр итогового экрана заменён с одного `seat` на массив `selectedSeats`, поскольку можно выбрать несколько билетов. |
| `screens/ConfirmationScreen.tsx` | Получает массив мест, выводит их номера и вычисляет итоговую цену по количеству билетов. |
| `screens/SearchScreen.tsx` | Существующие обновления состояния транспорта и полей ввода переведены на функциональную форму `setState(prev => ...)`, требуемую методичкой ЛР4. |
| `README.md`, `PROJECT.md` | Описывают актуальный сценарий, расположение логики и запуск приложения. |

## Где выполнены требования ЛР4

В `SeatsScreen.tsx` состояние `favoriteIds: number[]` хранит номера отмеченных свободных мест. `toggleFavorite` удаляет номер через `filter` или добавляет через новый массив `[...prev, seat]`: исходный массив не меняется. Кнопка с сердечком находится рядом с каждым компонентом `Seat` внутри `renderItem`.

Состояние `filter` принимает `all` или `favorites`. Вкладки «Все места» и «Избранные» меняют его и выделяют активный режим. Массив `visibleSeats` вычисляется из `seats` и `favoriteIds`; для пустой вкладки задан `ListEmptyComponent`. `extraData` помогает `FlatList` обновлять видимые элементы после изменения отметок и выбора.

Состояние `passengerCount` задаёт от 1 до 4 пассажиров. Обработчики `decreaseCount` и `increaseCount` ограничивают значение через `Math.max` и `Math.min`. `selectedSeats` хранит выбранные свободные места; занятые места отключены, количество выбранных ограничено числом пассажиров. При уменьшении счётчика лишние выбранные места удаляются. `total` вычисляется из `trip.priceValue * passengerCount` при рендере и не дублируется в состоянии.

Тернарный оператор выбирает полный или отфильтрованный список и меняет подписи интерфейса. Условие `selectedSeats.length > 0 && ...` показывает номера выбранных мест только после выбора. Кнопка подтверждения доступна, когда число выбранных мест равно числу пассажиров.

## Сценарий и запуск

`Вход → Поиск → Рейсы → Выбор мест → Итог`. На экране мест отметьте свободные места сердечком, переключите вкладку, задайте число пассажиров и выберите для каждого свободное место. В итог передаётся массив номеров; данные рейсов остаются локальными, оплата и бронирование не выполняются.

Из каталога проекта: `npm install`, `npm run start`; для проверки типов — `npm run typecheck`. В Expo можно открыть веб-версию клавишей `w` или приложение в Expo Go.
