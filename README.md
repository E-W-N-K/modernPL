# Попути – лабораторная работа № 3

Мобильное приложение на React Native и Expo для варианта 24. Дизайн и сценарий основаны на макетах из `lr2/exports`.

## Запуск

```powershell
npm.cmd install
npm.cmd run start
```

В терминале Expo нажмите `w` для браузера или откройте QR-код в Expo Go. Для проверки типов: `npm.cmd run typecheck`.

Описание структуры и связи кода с заданием — в [PROJECT.md](PROJECT.md).

Сценарий: вход → поиск поезда или автобуса → найденный рейс → выбор мест → итог поездки → новый поиск. На экране мест можно отметить избранные места, переключить фильтр и выбрать от 1 до 4 пассажиров. Стоимость рассчитывается по числу пассажиров. Занятые места заблокированы. Учебные данные рейсов локальны, оплата и бронирование не выполняются.
